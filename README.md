# Real-Time-Object-Detection-System

🎯 YOLO Vision AI

Real-Time Object Detection Using YOLO & Streamlit

YOLO Vision AI is a computer vision project designed to detect and classify objects in real time using a pre-trained YOLO model.

The application provides an interactive and user-friendly Streamlit interface that allows users to perform object detection through a live browser camera or uploaded images.

🚀 Key Features

- Real-time object detection using YOLO.
- Live camera detection through the browser.
- Image upload and object analysis.
- Object classification with bounding boxes and confidence scores.
- Select specific object classes to detect.
- Adjustable Confidence and IoU thresholds.
- Interactive dashboard with detection results.

🛠️ Technologies Used

- Python
- YOLO (Ultralytics)
- Streamlit
- OpenCV
- NumPy
- Streamlit-WebRTC
- Pillow

🎯 Project Goal

To build an interactive AI-powered computer vision application that demonstrates real-time object detection and makes pre-trained deep learning models accessible through a simple web interface.
